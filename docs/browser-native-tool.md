# 对话浏览器直接工具

`tomako_browser` 复用 Skills-OL 的 `tomako-browser.mjs` 和 Portal 已注册的浏览器能力；
不新增业务端点、权限来源或自然语言路由。浏览器租约、任务归属、人工接管和执行回执仍由 Portal 负责。

工具暴露 `tabs/open/status/read/screenshot/navigate/act/close`。普通操作直接依照 schema，
专用登录、验证码、上传和外链流程才读取浏览器手册。页面文字仅是数据，不提供操作授权。
`tabs` 只读本人已配对扩展的标签元数据；`open(tab)` 明确接手、不导航，已有输入保留。
若页面已变化、被关闭或已由其他任务使用，返回原因，不悄悄替换为新标签页。

每次调用冻结当前任务权限，JSON 经 stdin 交给可信 helper，不经过 shell，不接受调用者环境、
脚本路径或凭据。写操作自动生成 requestId，结果未知时保留标识并要求先核对；不自动重放。
截图在同一工具回执内附图片，临时文件与权限文件在调用结束后清理。停止或结束回合会取消
该回合正在运行的 helper；已发出的网页动作仍需以 Portal 回执和页面读回判断。

新对话在启动时注册直接工具；旧对话保留历史和原工具集合，通过每轮指令使用同一 helper。
每轮同时刷新完成回复规则：简单动作只给一句结果，可靠成功回执后停止重复检查；文章、
图片等任务交付成果本身，不附加重复过程说明。不会截断用户要求的内容。

相关验证：`go test ./agent/codex`、`go test ./...`、`go build ./...`。
真实验收还需要冻结 Skills-OL、Portal、cc-connect 版本，确认扩展安装版本，以及从本地
3000 和 Test 各执行一次保留部分输入的页面接手，核对同一 tabId、输入、图标与最终回复。
